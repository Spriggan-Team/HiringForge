# HiringForge

Develop an ATS (Applicant Tracking System) application to centralize, structure, and optimize the management of job applications.


##  Project  Initialisation

First, we need to check your current PHP version.
To display it in your terminal, you can run the following command:

    php --version

To start this application, you need to ensure that you are using PHP version 7 or higher.
Otherwise, please download the appropriate version from the following site:  https://www.php.net/downloads.php


The next step is to make sure you have Composer installed on your computer.
If Composer is not installed, you can install it from the following site:  https://getcomposer.org
